# Commercial cost ledger
Extend commercial catalogue; do not replace legacy snapshots until reconciliation. FOCUS-inspired, not conformance certified. References: https://focus.finops.org/docs/specification/v1-4/sections/appendix/saas-examples/ ; https://help.zluri.com/docs/create-a-contract ; https://www.finops.org/framework/technology-categories/saas/
Separate signed commitment, entitlement, invoice/due, actual settlement, and approved expense allocation timelines. Never add totals across bases. Preserve source evidence and signed document lineage. Components: seats, platform, credits, contact/send blocks, storage, services, maintenance, implementation, support, taxes, discounts and adjustments. Preserve native unit, scale, currency, effective period, pricing schedule, evidence and quantity tiers. Unallocated bundled costs must not be inferred as licence prices. PUPM only from seat costs and compatible seat-months; all-in allocation separately labelled. Demand drivers include headcount, contact volume, consumption and milestones. Planning assumptions cannot become contractual facts. Explicit approval for expense allocation; no automated accounting posting. Reconcile each basis independently against signed totals, invoices and payments; flag missing facts and prevent duplicate source records. Add phased APIs, migration compatibility, UI and regression tests before exposure.
