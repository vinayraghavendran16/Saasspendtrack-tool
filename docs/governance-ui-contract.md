# Frontend integration contract
Keep navigation hidden until server authorization and migrations are validated. Procurement views: parties and roles, products and SKUs, contracts and lines, annualized recurring spend by currency. Governance views: ownership and acceptance, cases and SLA deadlines, overdue resolution. Use textContent for untrusted labels. Never sum currencies. Existing governance ownership uses legacy subscription IDs, while commercial contracts use contract IDs: introduce an explicit mapping before enabling contract renewal routing.
