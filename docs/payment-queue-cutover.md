# Payment notification cutover
Do not enable the queue while the webhook sends confirmations directly. Replace the immediate sender only after migration 015, queue tests and provider sandbox checks pass. Use a default-off scheduler flag. Verify provider acceptance separately from inbox delivery. Claim each job with a fresh unique lease token and bounded timeout; retry ambiguous provider responses with documented duplicate risk. Record dead jobs and expose admin review. Reconcile already-sent confirmations before enabling. Payment failure events must be authenticated and linked to a known customer/payment attempt; never revoke existing paid access merely because another payment failed.
