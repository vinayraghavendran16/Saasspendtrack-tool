# PUPM metric contract v1
All consumers (dashboards, reporting, AOP, TrackAI) use the same scoped metric service. Required: account, scope type and ID, month, currency, cost basis (invoiced/run_rate/forecast), denominator type, population observation method, active window where applicable, source IDs, as-of time, definition version and completeness. Preserve exact minor-unit numerator and integer denominator; round only for display. Missing population is unavailable, never zero. Forecast is not actual or commitment. Do not average ratios or sum overlapping users. Server derives tenant identity and enforces scope; client cannot authorize itself. No ingestion writes until canonical source mapping and idempotency constraints are verified. TrackAI must disclose basis and missing data. Historical helper currently supports invoiced and run_rate only; forecast integration remains pending.
