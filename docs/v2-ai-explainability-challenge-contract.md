# AI explainability, evidence traceability and challenge
Every material AI recommendation, decision proposal, extracted assertion and generated insight must expose a consistent Why this? / View evidence / Challenge interface wherever rendered, including TrackAI, renewals, risk, financials, reports, AOP, procurement and executive views.

## Evidence
Store tenant-scoped immutable recommendation revisions with concise user-facing rationale (not hidden model reasoning), assumptions, limitations, alternatives, calculation definition/version, model/version, generation time and evidence references. Evidence references identify artifact ID, immutable version/digest, page, section/clause, text span or structured record/field and observation timestamp. MSA, order forms, amendments, invoices, usage, reports, employee aggregates and external sources are supported. Exact excerpts must be validated against the authorized artifact version; no invented clause numbers or quotations. Distinguish direct evidence, derived calculation, inference and missing evidence. Resolve conflicts explicitly; do not assume document precedence. Source viewer enforces current tenant and artifact permissions, redaction, deletion and retention. Mark unavailable or changed evidence; never silently substitute newer evidence. Confidence must be evidence-quality based, not fabricated probability.

## Challenge lifecycle
User can dispute source accuracy, interpretation, assumptions, calculation, completeness or recommendation; attach authorized counterevidence and correction. Preserve original revision; create a challenge record with actor/time/reason/evidence, status and resolution. Reassess against authorized evidence; return upheld/revised/withdrawn/insufficient evidence with explanation and new revision where appropriate. No automatic execution, approval or alteration of original artifact. Material revision invalidates prior approval for execution until renewed review. Unresolved material challenges block automated execution. Audit challenge, reassessment, source access and approval events using shared audit infrastructure. Learning only from authorized reviewed outcomes, not raw disputes or unverified AI claims.

## Rollout
Inventory all AI output surfaces and existing evidence mechanisms; shared evidence/revision/challenge schema; permission-aware source resolver and citation verification; challenge API and state machine; reusable UI component; integrate module by module; test fabricated citations, cross-tenant access, stale evidence, prompt injection in artifacts, approval invalidation, concurrent challenges, redaction and accessibility. Default off until verified; frozen V1 unchanged.
